Just a simple modular zsh config made from [this gist](https://gist.github.com/maxogod/6c82ceea2f9229f5549004ae0337553e).

## Pre-requisites

1. Install zsh: `sudo apt install zsh -y`
2. Make default shell: `chsh -s $(which zsh)`
3. Fetch autosuggestions: `git clone https://github.com/zsh-users/zsh-autosuggestions.git ~/.zsh/zsh-autosuggestions`

## How to setup

```bash
git clone git@github.com:maxogod/maxo-zsh.git ~/.config/zsh

cp ~/.config/zsh/.zshenv ~/.zshenv
```
